## 🎨 1. UI 设计体系：资源模块化重构

为了提升系统的可维护性，我对 UI 进行了底层逻辑的彻底重构。

* **资源解耦 (Component-based Design)**：
    * **核心改动**：放弃了以往“一图一按钮”的冗余设计，实现了**按钮基底 (Base) 与功能图标 (Icon)** 的完全分离。
    * **技术优势**：  
        * **视觉一致性**：通过基底切片复用，确保 21 个功能按键在阴影、圆角及光影特效上达到像素级的统一。

* **侧边栏 (Sidebar) 视觉进化**：
    * **图标化策略**：进入子功能节点后，侧边栏采用“图标识别”替代传统的“文字标题”。
    * **设计考量**：完美解决了多语言或长字符在窄侧边栏中导致的**文字截断 (Truncation)** 或**强行换行**问题，界面更显整洁且具工业美感。

## 🏗️ 2. 菜单系统与节点架构 (Menu System)

通过建立严谨的逻辑状态机，确保了 21 个子功能模块在复杂交互下的稳定性。

* **全功能逻辑闭环**：在 Menu 节点下完整构建了 **21 个子功能模块** 的进入与退出 (Enter/Exit) 状态机，确保内存申请与释放的安全性。
* **高效导航逻辑**：
    * **物理按键映射**：优化了 `KEY_UP` 与 `KEY_DOWN` 的轮询逻辑，支持在 21 个图标间快速跳转及无限循环滚动。
    * **精准焦点反馈**：配合分离式基底，利用 LVGL Style 机制实现了极其灵敏的**焦点选中 (Focused)** 视觉反馈。

---

## ⚡ 3. 交互性能提升：多模态操作 (Multimodal)

我们实现了“触控 + 物理按键”的双链路融合，提升了设备在不同工业环境下的适用性。

* **全链路触控支持**：
    * **直达逻辑**：支持在主界面直接点击图标进入对应的菜单节点。
    * **深度跳转**：在菜单界面，支持点击 21 个功能图标精准跳转至三级子页面。
* **交互兼容性 (Input Compatibility)**：
    * 建立了完善的**输入设备驱动层**，实现了触摸坐标与物理按键值的逻辑对齐。
    * 无论用户习惯使用旋钮、按键还是触摸屏，系统均能保持一致的响应速度与逻辑路径。
